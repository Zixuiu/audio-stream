========================================
手机音频投屏到电脑 - 使用指南
========================================

✅ scrcpy v3.3.4 已安装
   - 支持屏幕镜像
   - 支持音频转发（Android 11+）

========================================
第一步：配置手机
========================================

1. 开启开发者选项：
   设置 → 关于手机 → 连续点击"版本号"7次

2. 开启USB调试：
   设置 → 开发者选项 → USB调试（开启）

3. 允许USB调试：
   连接电脑后，手机弹出提示时选择"允许"

========================================
第二步：连接手机到电脑
========================================

方式1：USB连接（推荐，低延迟）
  - 使用USB数据线连接手机和电脑
  - 确保选择"文件传输"模式

方式2：WiFi连接（无线）
  - 手机和电脑连接同一WiFi
  - 先用USB连接一次配置，之后可拔线

========================================
第三步：启动投屏+音频
========================================

方式1：USB连接启动
  1. 打开终端（CMD/PowerShell）
  2. 输入：scrcpy --audio-codec=aac
  3. 回车，手机屏幕和音频会出现在电脑上

方式2：WiFi连接（首次需要USB配置）
  1. 先用USB连接
  2. 执行：adb tcpip 5555
  3. 拔掉USB线
  4. 查看手机IP（设置 → 关于手机 → 状态 → IP地址）
  5. 执行：adb connect 手机IP:5555
  6. 执行：scrcpy --audio-codec=aac

========================================
常用参数
========================================

scrcpy --audio-codec=aac -m 1024
  → 限制分辨率，提高性能

scrcpy --audio-codec=aac -S
  → 投屏时关闭手机屏幕（省电）

scrcpy --audio-codec=aac --stay-awake
  → 保持手机唤醒

scrcpy --audio-codec=aac --fullscreen
  → 全屏显示

========================================
注意事项
========================================

- 音频转发需要 Android 11 或更高版本
- 如果音频不工作，尝试：
  * scrcpy --audio-source=output
  * 检查手机是否静音
  * 检查电脑音量

========================================
快速启动脚本
========================================

你可以创建一个 batch 文件来快速启动：
  1. 新建文件 start.bat
  2. 输入：scrcpy --audio-codec=aac --stay-awake
  3. 保存
  4. 双击即可启动
